# Standard Evaluation Datasets

## Coding Benchmark
- **Source**: HumanEval, MBPP (Multi Programming Benchmarks)
- **Tasks**: Function implementation, code completion, bug fixing
- **Evaluation**: Execute generated code, check correctness

## Reasoning Benchmark  
- **Source**: BigBench, StrategyQA
- **Tasks**: Logical reasoning, mathematical problems
- **Evaluation**: Compare answers with ground truth

## Knowledge Benchmark
- **Source**: TriviaQA, Natural Questions
- **Tasks**: Factual question answering
- **Evaluation**: Exact match, fuzzy match scores

## Summarization Benchmark
- **Source**: CNN/DailyMail, XSum
- **Tasks**: Text summarization
- **Evaluation**: ROUGE scores, human evaluation

## Conversation Benchmark
- **Source**: PersonaChat, DSTC
- **Tasks**: Conversational AI
- **Evaluation**: Engagement, coherence, persona consistency
