# Custom Domain Benchmarks

## Medical Domain
- **Tasks**: Diagnosis, treatment recommendations, medical Q&A
- **Evaluation**: Clinical accuracy, safety compliance
- **Constraints**: Must not provide harmful medical advice

## Legal Domain
- **Tasks**: Contract analysis, legal research, case summary
- **Evaluation**: Legal accuracy, citation correctness
- **Constraints**: Must include disclaimers

## Financial Domain
- **Tasks**: Financial analysis, market prediction, risk assessment
- **Evaluation**: Prediction accuracy, risk identification
- **Constraints**: Must include investment disclaimers

## Technical Domain
- **Tasks**: Code review, architecture design, debugging
- **Evaluation**: Solution correctness, best practices adherence
- **Constraints**: Security and performance considerations
