# Self-Critique Template

Use this template for reviewing and improving responses:

```
## Original Response
{{ original_answer }}

## Self-Critique

### 1. Accuracy Check
- **Facts stated**: {{ list key facts }}
- **Verified**: {{ which are confirmed correct }}
- **Unverified**: {{ which need checking }}
- **Potential errors**: {{ possible mistakes }}

### 2. Completeness Check
- **Missing information**: {{ what was omitted }}
- **Unanswered questions**: {{ what wasn't addressed }}
- **Edge cases**: {{ what scenarios are missing }}

### 3. Clarity Check
- **Hard to understand**: {{ what is confusing }}
- **Jargon used**: {{ technical terms defined? }}
- **Structure**: {{ is it well organized? }}

### 4. Tone Check
- **Appropriate for audience**: {{ yes/no }}
- **Professional**: {{ yes/no }}
- **Helpful**: {{ yes/no }}

### 5. Safety Check
- **Harmful content**: {{ yes/no }}
- **Sensitive topics**: {{ what needs care }}
- **Disclaimers needed**: {{ what warnings }}

## Improvements

### Changes Made
1. {{ first improvement }}
2. {{ second improvement }}
3. {{ third improvement }}

### Final Answer
{{ improved answer }}
```

## Example

```
Original Response: "Python is a programming language created by Guido van Rossum."

Self-Critique

1. Accuracy Check
- Facts: Created by Guido van Rossum, it's a programming language
- Verified: Both correct
- Potential errors: None obvious

2. Completeness Check
- Missing: Year of creation (1991), key features, use cases
- Unanswered: What makes Python special?
- Edge cases: Not covering Python 2 vs 3

3. Clarity Check
- Hard to understand: Nothing, it's simple
- Jargon: "programming language" is defined
- Structure: Single sentence, fine for this

4. Tone Check
- Appropriate: Yes
- Professional: Yes
- Helpful: Could be more helpful

5. Safety Check
- Harmful: No
- Sensitive: No
- Disclaimers: None needed

Improvements
1. Added year of creation
2. Mentioned key features
3. Added use cases

Final Answer: "Python is a high-level programming language created by Guido van Rossum in 1991. It features dynamic typing, automatic memory management, and is widely used for web development, data science, AI, and automation."
```
