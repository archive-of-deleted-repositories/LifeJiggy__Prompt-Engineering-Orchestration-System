# Task Decomposition Guide

Breaking complex tasks into manageable steps is essential for reliable AI execution.

## When to Decompose

- Multi-step workflows
- Complex projects
- Tasks requiring different skills
- Long-term goals
- Collaborative efforts

## Decomposition Framework

1. **Identify the Goal**: What is the desired end state?
2. **List Requirements**: What is needed to achieve the goal?
3. **Order Dependencies**: What must come first?
4. **Estimate Effort**: How complex is each step?
5. **Define Success**: How do we know each step is complete?

## Example: Build a Web Application

```
Goal: Build an e-commerce product page

Step 1: Requirements Gathering
- [ ] Define product data structure
- [ ] Identify required UI components
- [ ] List user interactions

Step 2: Backend Setup
- [ ] Set up API endpoints
- [ ] Create product models
- [ ] Implement database queries

Step 3: Frontend Development
- [ ] Build product display component
- [ ] Add to cart functionality
- [ ] Implement quantity selector

Step 4: Integration
- [ ] Connect frontend to API
- [ ] Test all interactions
- [ ] Verify error handling

Step 5: Polish
- [ ] Add loading states
- [ ] Implement responsive design
- [ ] Add accessibility features
```

## Best Practices

1. **Independent Steps**: Each step should be self-contained
2. **Clear Inputs/Outputs**: Define what each step needs and produces
3. **Error Handling**: Plan for failure at each step
4. **Review Points**: Add checkpoints between major steps
5. **Flexibility**: Allow for iteration and backtracking
